۳ چک‌لیست آپلود در کافه‌بازار

  1. فایل APK/AAB را آماده کنید (بخش ۴ همین صفحه) و در پنل «کافه‌پست» آپلود کنید.
  2. آیکون ۵۱۲×۵۱۲ را از بخش ۲ همین صفحه آپلود کنید.
  3. ۹ اسکرین‌شات را به ترتیب بخش ۱ آپلود کنید.
  4. متن‌ها را از فایل bazaar-listing.md کپی کنید: توضیح کوتاه، توضیحات کامل و «تازه‌ها».
  5. دسته «مالی و حسابداری» و محتوای «برای همگان» را انتخاب کنید.
  6. وب‌سایت پشتیبان = آدرس مخزن گیت‌هاب + ایمیل پشتیبانی را وارد کنید.

۴ مرحله باقی‌مانده: ساخت فایل APK

نسخه فعلی برنامه یک وب‌اپ پیش‌رفته (PWA) است که همین حالا هم قابل نصب روی گوشی است؛ اما کافه‌بازار فایل APK می‌خواهد. دو راه ساده:

راه ۱ — PWABuilder (ساده‌ترین، بدون کدنویسی)

  1. اول برنامه را روی یک هاست عمومی منتشر کنید (مثلاً Vercel — مخزن گیت‌هاب آماده است).
  2. به pwabuilder.com بروید و آدرس عمومی برنامه را وارد کنید.
  3. گزینه Android → Package را بزنید؛ خروجی «TWA» همان برنامه با همان manifest و آیکون‌های فعلی است.
  4. فایل app-release-signed.apk / .aab را دانلود و در کافه‌بازار آپلود کنید.

راه ۲ — Capacitor + Android Studio

  1. npm i @capacitor/core @capacitor/cli و سپس npx cap add android
  2. سرور را به آدرس هاست عمومی برنامه اشاره دهید و پروژه را در Android Studio باز کنید.
  3. Build → Generate Signed Bundle / APK
💡 منیفست PWA (public/manifest.webmanifest) و همه آیکون‌ها همین حالا آماده و استاندارد هستند؛ در هر دو راه دقیقاً از همین‌ها استفاده می‌شود.
